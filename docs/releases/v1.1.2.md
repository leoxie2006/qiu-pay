# Qiu-Pay v1.1.2

## 安全修复
- 支付页面仅对已支付订单签发 `TRADE_SUCCESS` 回跳凭证；未支付及超时订单不再获得成功签名。
- 回调服务在通知、重试及回跳构建时校验支付状态；构建异常时不返回未经校验的原始链接。
- 支付完成后前端重新获取回跳链接，兼容新的签发时机。

## 修复与工程改进
- 修复商户密钥重置及订单列表筛选问题。
- 修复本地开发时前端代理与后端连接问题。
- 增加 PR/Issue 模板与 PR 规范。
- 增加 CI、GHCR 镜像发布与独立 demo 部署脚本，包含 SQLite 一致性备份、健康检查和镜像回滚。
- 回归测试不再依赖本机是否已构建 SPA。

## 验证及发布范围
- main CI 后端 **307 项通过**，前端构建与实际容器三状态验证通过。
- 发布不代表生产已升级；本次不部署生产和远端 demo，不修改真实订单。
- Docker 主机时区跟随和 tag 自动 Release 流程正在独立 PR 中审查，**不包含在此版本**。
- 本版本无数据库 schema 迁移；回退镜像应保留当前订单库，避免覆盖新订单。
