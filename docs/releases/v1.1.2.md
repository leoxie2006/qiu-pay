# Qiu-Pay v1.1.2

## 修复

- 修复未支付、已超时订单也能获得支付成功签名的问题。
- 支付完成后重新获取回跳链接，避免因签名签发时机变化而影响跳转。
- 修复商户密钥重置和订单列表筛选异常。
- 修复本地开发时前端连接后端失败的问题。

## 安装与更新

Docker 镜像：`ghcr.io/leoxie2006/qiu-pay@sha256:790177f1821a15d6e5b27c112d5cd6fad428f89d0215d9313df3c078034f999e`，支持 `linux/amd64`。

首次安装可下载本版本源码，复制 `.env.example` 为 `.env`，修改管理员密码和 `JWT_SECRET`，将 `BACKEND_HOST` 设为 `0.0.0.0`。

将 `docker-compose.yml` 中的 `image` 设置为上述镜像地址，然后启动：

```sh
docker compose pull
docker compose up -d
```

从旧版本更新前，先备份 `.env`、数据库和上传文件。备份 SQLite 数据库时先停止容器，或使用 SQLite 在线备份，不要直接复制正在写入的数据库。保留现有数据卷和配置，修改镜像地址后运行上述命令。

本版本不需要迁移数据库。更新后确认后台可登录、订单查询正常，以及已支付订单可以正常回跳。
