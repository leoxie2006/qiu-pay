# Qiu-Pay v1.1.3

## Docker 主机时区修复
- 根 Compose、demo Compose 和 README 示例只读挂载主机 `/etc/localtime`，让容器本地时间跟随主机时区，不硬编码 `Asia/Shanghai`。
- 支持 `HOST_TIMEZONE_FILE` 指定有效时区文件；禁止将缺失的文件路径自动创建为目录。
- 运行镜像安装 `tzdata`，支持有明确需求时设置显式 `TZ`；要跟随主机请移除会覆盖挂载的 `TZ`。
- 实际隔离验证：默认 UTC、主机文件 +08:00、UTC 文件 +00:00，UNIX 时间与主机一致。

## 自动发布
- 稳定版本 tag `vMAJOR.MINOR.PATCH` 触发 GitHub Release。
- 校验 tag 的 main 归属，复用 main CI 已发布的 SHA 镜像，校验 revision 并按 digest 验证后发布 GHCR 版本标签。
- Release 附更新说明、commit、不可变镜像 digest 和 `release-manifest.json`。
- 保留已存在的 Release，支持手动重试；不执行生产或远端 demo 部署。

## 发布一致性
- 默认 Compose 与 README 推荐入口切换为 GHCR `v1.1.3`，避免继续拉取未同步更新的 Docker Hub `latest`。
- 可用 `QIUPAY_IMAGE` 覆盖镜像；生产建议使用下方经过验证的不可变 digest。
- 本次没有更新 Docker Hub 标签。

## 升级注意
- 不改写既有订单或数据库 schema，不设置 `SYS_TIME`，不执行 `date -s`。
- 主机更换时区文件后需重建容器；旧数据库是无时区时间串，切换前需要评估跨区时间比较，不能将挂载视为历史时间迁移。
- Windows/macOS/Docker Desktop 使用 Docker 可访问的有效 TZif 文件；当前发布镜像平台为 `linux/amd64`。
- 本次只发布，不部署生产或远端 demo，也不重启现有服务。
