# Qiu-Pay v1.1.3

## 修复

- 修复 Docker 容器与主机时区不一致的问题，订单时间和日志时间默认跟随主机时区。
- 更新默认 Docker 镜像地址，避免安装时拉取旧版本。

## 新增

- 支持用 `HOST_TIMEZONE_FILE` 指定时区文件；默认使用主机的 `/etc/localtime`。

## 安装与更新

### 首次安装

```sh
git clone --branch v1.1.3 https://github.com/leoxie2006/qiu-pay.git
cd qiu-pay
cp .env.example .env
```

编辑 `.env`，修改管理员密码和 `JWT_SECRET`，将 `BACKEND_HOST` 设为 `0.0.0.0`，再启动：

```sh
docker compose pull
docker compose up -d
```

访问 `http://服务器IP:8000`。当前 Docker 镜像支持 `linux/amd64`。

### 从旧版本更新

先备份 `.env`、数据库和上传文件。备份 SQLite 数据库时先停止容器，或使用 SQLite 在线备份，不要直接复制正在写入的数据库。

将 `docker-compose.yml` 更新为本版本配置，保留现有端口、数据卷和 `.env`。设置镜像为 `ghcr.io/leoxie2006/qiu-pay:v1.1.3`，然后执行：

```sh
docker compose pull
docker compose up -d --force-recreate
```

本版本不需要迁移数据库。更新后检查后台显示的时间：若主机时区与旧容器不同，旧订单时间不会自动转换，请先确认时间差对未完成订单的影响。

主机没有 `/etc/localtime` 时，设置 `HOST_TIMEZONE_FILE` 指向有效的时区文件。要跟随主机时区，请移除原有的 `TZ` 设置；主机切换时区后需重建容器。
