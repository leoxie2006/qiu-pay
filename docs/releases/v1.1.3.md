# Qiu-Pay v1.1.3

## 修复

- 修复 Docker 容器与主机时区不一致的问题，订单时间和日志时间默认跟随主机时区。
- 更新默认 Docker 镜像地址，避免安装时拉取旧版本。

## 新增

- 支持用 `HOST_TIMEZONE_FILE` 指定时区文件；默认使用主机的 `/etc/localtime`。

## 安装与更新

安装和更新步骤见 [README 的 Docker 部署说明](https://github.com/leoxie2006/qiu-pay#-docker-部署推荐)。

推荐镜像：`ghcr.io/leoxie2006/qiu-pay:latest`。
